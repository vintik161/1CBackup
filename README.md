# 1CBackup
Скрипт для резервного копирования файловых баз 1С
Моя версия скрипта для резервного копирования файловых баз 1С
Настрйоки
set "BASE_DIR=X:\1c_bases" Папка с базами данных
set "BACKUP_ROOT=\\192.168.18.7\backup$" Папка с бэкапами
set "ZIP=C:\Program Files\7-Zip\7z.exe" Путь к 7z
set "LOG_DIR=C:\backup_bat\log" Путь к логам
set "EXCLUDE_FILE=C:\backup_bat\exclude.lst" Исключения, файлы которые не архивируем
Скрипт работает следующим образом. Создаёт архивы 7z с максимальной степенью сжатия поочередно для каждой папки содержащейся в BASE_DIR
На выходе получаем файл Имя_Бфзы_26-03-11_21-15.7z
